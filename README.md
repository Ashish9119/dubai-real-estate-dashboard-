[9:21 am, 12/05/2026] Ashish Singh: ## Project Overview
This project analyzes Dubai real estate market data using Power BI.  
The dashboard provides insights into property pricing, neighborhood trends, listing categories, and property sizes.

---

## KPIs
- Total Listings
- Average Price
- Average Property Size
- Highest Priced Property
- Average Price Per Sqft

---

## Charts Used
- Bar Chart
- Pie Chart
- Scatter Plot
- Treemap
- Line Chart
- Map Visualization
- Slicer Filters

---

## Key Insights
- Urban properties have higher average prices.
- High-end listings occupy larger square footage.
- Property prices decrease as property age increases.
- Suburban areas contain a large number of listings.

---

## Tools Used
- Power BI
- Excel / CSV Dataset
- GitHub
